# Roosterplanner (demo)

Installeerbare web-app voor het rooster van de vakgroep: eigen rooster, wie staat waar, bezettingscheck en afwezigheid aanvragen.

**Openen:** https://boudewijn122.github.io/Roosterplanner/

Op de iPhone: open de link in Safari → Deel → **Zet op beginscherm**.

Let op: dit is een demo met geanonimiseerde namen (Chirurg A–H, AIOS 1–6). Aanvragen worden alleen op het eigen toestel bewaard.

Na een wijziging: verhoog `VERSION` in `sw.js`, zodat telefoons de nieuwe versie ophalen.
